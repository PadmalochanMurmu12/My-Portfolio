FoodKart- Playwright Automation

Objective

Architected a scalable, self-running quality assurance framework to validate critical user journeys—from menu browsing to final checkout. Built with a Behavior-Driven Development (BDD) approach so product managers and non-technical stakeholders can read the test scenarios in plain English, while the engine ensures zero-downtime deployments.

Tech Stack & Architecture

  • • Core Engine: Playwright
  • • Language: TypeScript (strict type-checking and maintainability)
  • • Design Pattern: Cucumber (BDD) with plain-English Gherkin syntax
  • • Infrastructure: GitHub Actions (CI/CD automated execution on every pull request)
